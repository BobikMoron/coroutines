# Ресторан «Параллель»

Простой учебный проект на Kotlin и корутинах.

## Как запустить в IntelliJ IDEA

1. Откройте папку `IdeaProjects/untitled2` как проект.
2. Если файл `Main.kt` всё ещё красный, нажмите:
   **File → Reload All from Disk**.
3. Откройте `src/Main.kt`.
4. Нажмите зелёную стрелку рядом с `fun main()` и выберите **Run 'MainKt'**.

Библиотека корутин уже лежит в папке `libs` и подключена к проекту,
поэтому скачивать ничего не нужно.

## Что показывает программа

1. **Подготовка ингредиента** — `prepareIngredient` работает на `Dispatchers.Default`.
2. **Параллельная готовка** — внутри `coroutineScope` одновременно работают
   готовка, контроль температуры и мониторинг прогресса.
3. **Отмена заказа** — через 2 секунды вызывается `job.cancel()`,
   и обе задачи корректно останавливаются.
4. **Ошибка одного блюда** — исключение ловится внутри `launch`,
   поэтому остальные заказы продолжают готовиться.
5. **Проверка качества** — `async` возвращает `Deferred`, результат получаем через `await()`.
6. **Канал** — кухня отправляет 5 блюд, метрдотель читает их из `Channel`.

## Запуск без IntelliJ

Если установлен Gradle:

```bash
gradle run
```
